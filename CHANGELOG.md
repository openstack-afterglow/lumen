## 0.6.21 — 2026-11-19 (prepared; not yet published)

- **릴리스 / Release:** 릴리스 준비 상태이며 tag·이미지·배포는 아직 없다. 운영 버전은 계속 `0.6.20`이다. Afterglow 1.32.29와 짝을 이루며 Lumen을 먼저 배포한다. / Release preparation only: no tag, image or rollout yet; production stays on `0.6.20`. Pairs with Afterglow 1.32.29; deploy Lumen first.

- **한국어 — 도메인 범위(036):** 같은 사용자는 같은 Keystone 도메인 안의 어느 프로젝트에서나 같은 대화·검색, 에이전트, 개인 MCP 연결(OAuth·활성화 포함)과 사용자 HTTP 도구, 프로젝트 메모리를 본다. 도메인이 아직 채워지지 않은 행은 원래 프로젝트에서만 보인다. 실행·실행 기록·사용량 귀속·quota·클라우드 도구·자산은 계속 현재 선택한 프로젝트 권한을 쓴다. 선택 프로젝트 구성원 자격이 회수되면 공유 경로도 즉시 거절한다. 시작 시 잠금 기반 재개형 backfill(`python -m lumen.scripts.backfill_domain_scope --apply`)이 원 프로젝트를 Keystone으로 확인해 도메인을 채운다. 도메인 안에서 겹치는 MCP 연결·HTTP 도구는 최신 설정을 남기고 나머지를 자격 증명·승인과 함께 보관하며, 에이전트 바인딩은 남은 행으로 옮긴다. `GET /v1/archived-connections`·`POST /v1/archived-connections/{archive_id}/restore`(소유 사용자)와 `/v1/domains/{id}/archived-connections`(현재 도메인 관리자)로 목록 조회·복원한다. 목록은 메타데이터만 반환한다.
- **English — Domain scope (036):** The same user sees the same conversations and search, agents, personal MCP connections (OAuth and activations included), custom HTTP tools and project memories from any project in one Keystone domain. Rows without a backfilled domain stay visible in their origin project only. Runs, run journals, usage attribution, quotas, cloud tools and assets keep current-project authority. Revoking the selected-project membership immediately denies the shared paths. A lock-guarded, resumable backfill (`python -m lumen.scripts.backfill_domain_scope --apply`, also started by the API) resolves origin projects through Keystone. Duplicate MCP connections and HTTP tools across a domain keep the newest configuration and archive the rest with their credentials and approvals; agent bindings move to the winner. List and restore archives with `GET /v1/archived-connections` and `POST /v1/archived-connections/{archive_id}/restore` (owning user) or `/v1/domains/{id}/archived-connections` (current domain manager). Listings return metadata only.
- **한국어 — 도메인 크레딧 풀(037):** 대시보드 사용량은 사용자 지갑 대신 선결제 도메인 풀에서 차감한다. 시스템 관리자가 `POST /v1/admin/domain-pools/{domain_id}/topups`(`Idempotency-Key` 필수, 같은 키·본문 재전송은 안전)로 충전하고, 응답을 잃으면 `GET /v1/admin/domain-pools/{domain}/topups/{key}`로 원장을 확인한다(없으면 200 `found: false`). 도메인 관리자는 `/v1/domain-pool`에서 관리자 상한 아래 월 한도를 정한다. 사용자별 월 한도는 대시보드와 개인 키 사용을 합산하는 actor 단위 남용 방지 장치로 남는다. 잠금 순서는 도메인 풀 → 사용자 지갑 → 프로젝트 quota → 대화 → 실행 계보 → 예약 행으로 고정한다. 텍스트 모델 목록에 `domain_billing{ready, reason_code}`를 추가하고, 준비되지 않은 모델의 도메인 결제 실행은 422 `domain_billing (<reason_code>)`로 거절한다. 제목 모델이 준비되지 않았으면 문맥 압축은 실행 모델로 대신하며 `GET /v1/admin/title-model`이 이를 보고한다. 풀이 없는 도메인은 `domain_credit_insufficient`로 실패한다.
- **English — Domain credit pools (037):** Dashboard usage is billed to a prepaid domain pool instead of the user wallet. System administrators top up with `POST /v1/admin/domain-pools/{domain_id}/topups` (`Idempotency-Key` required; replaying the same key and body is safe) and recover a lost response with `GET /v1/admin/domain-pools/{domain}/topups/{key}` (200 `found: false` when absent). Domain managers set a monthly limit under the administrator ceiling at `/v1/domain-pool`. Per-user monthly limits remain an actor-wide abuse guard across dashboard and personal-key usage. Locks follow one order: domain pool → user wallet → project quota → conversation → run lineage → reservation rows. Text models expose `domain_billing{ready, reason_code}`; domain-paid admission refuses an unready model with 422 `domain_billing (<reason_code>)`. When the title model is not ready, context compaction falls back to the execution model, reported by `GET /v1/admin/title-model`. Unfunded domains fail with `domain_credit_insufficient`.
- **한국어 — 사용량 보기:** Keystone 세션의 `/v1/usage`, `/timeseries`, `/keys`, `/records` 기본 보기는 결제자와 관계없이 본인 사용량(037 이전 기록, 개인·Claude Gateway 키 사용, 본인의 도메인 결제 사용)이다. `scope=domain`은 실시간 도메인 관리자에게만 도메인 풀 사용량을 보여 주며(구성원은 403 `domain_manager_required`), 다른 구성원의 식별자는 가린다. 모든 행과 집계에 `billing_scope`(`user`/`domain`)가 붙는다. `/v1/usage` 요약은 관리자 확인 없이 구성원에게 현재 도메인 풀의 읽기 전용 집계 `domain_pool`(`exists`, `funded`, 잔액·예약·당월 사용·유효 월 한도)을 함께 준다. 풀이 없는 도메인(예: Personal)은 `exists: false, funded: false`다. Migration 037은 일부만 적용된 뒤에도 다시 실행할 수 있다.
- **English — Usage views:** A Keystone session's `/v1/usage`, `/timeseries`, `/keys` and `/records` default to the caller's own usage across every payer: history from before migration 037, personal and Claude Gateway key usage, and the caller's domain-paid usage. `scope=domain` shows the domain pool's usage to live domain managers only (members get 403 `domain_manager_required`) and masks other members' identifiers. Every row and aggregate carries `billing_scope` (`user` or `domain`). The `/v1/usage` summary also gives any member a read-only `domain_pool` with the current domain pool's aggregates (`exists`, `funded`, balance, reserved, monthly used, effective monthly limit), with no manager check. A domain with no pool, such as Personal, returns `exists: false, funded: false`. Migration 037 can be re-run after a partial failure.
- **한국어 — 개인·서비스 키(038):** 키는 모델 API 전용이다. 개인 키는 사용자에게 묶이고 프로젝트 헤더를 무시하며 사용자 지갑으로 결제한다. 서비스 키는 도메인 소유이며 도메인 풀로 결제하고, 매 요청 실시간 확인한 현재 도메인 관리자만 발급·관리한다(`GET /v1/service-keys/issuance-policy`가 허용 scope와 route를 반환). 생성자가 역할을 잃어도 서비스 키는 유지된다. 키에는 OpenStack 권한·대화 기록·메모리가 없다. 클라이언트가 실행하는 function/custom 도구는 그대로 허용하고, Lumen이나 공급자가 실행하는 hosted 도구는 403 `server_tool_not_allowed_for_key`로 거절한다. OpenAI `shell`은 `environment.type == "local"`일 때만 클라이언트 도구다. 내장 검색 모델(Sonar)은 아래 서버 도구 모델 항목을 따른다.
- **English — Personal and service keys (038):** Keys are model-API only. Personal keys are user-bound, ignore project headers and bill the user wallet. Service keys are domain-owned, bill the domain pool and are issued and managed only by current domain managers, verified live on every request (`GET /v1/service-keys/issuance-policy` returns the accepted scopes and routes). Service keys survive the creator losing the manager role. Keys carry no OpenStack authority, conversation history or memory. Client-executed function/custom tools pass through; tools executed by Lumen or the provider return 403 `server_tool_not_allowed_for_key`. OpenAI `shell` counts as a client tool only with `environment.type == "local"`. Built-in search models (Sonar) follow the server-tool models entry below.
- **한국어 — 전환 키 scope(038):** 키 목록·조회·관리자 인벤토리의 `scopes`는 인증이 실제로 적용하는 모델 scope만 반환한다. 038로 전환된 키(`created_by_user_id` 없음)에 남은 `native:*` scope는 저장 데이터에 그대로 두지만 표시하지 않는다. 전환 키는 0.6.20 접근을 유지하도록 `compat:completions:write`나 `native:runs:write`가 있으면 `embeddings:write`·`decisions:write`도 갖는다(새 키는 해당 없음). / **English — Converted key scopes (038):** Key list/get and admin inventory `scopes` report only the model scopes that authentication enforces. Legacy `native:*` scopes left on keys converted by 038 (no `created_by_user_id`) stay stored but are not shown. To keep 0.6.20 access, a converted key holding `compat:completions:write` or `native:runs:write` also gets `embeddings:write` and `decisions:write`; newly issued keys do not.
- **한국어 — 모델 행 식별(039):** 네이티브 채팅·문맥·Decisions·이미지·음성·실시간 요청과 에이전트는 카탈로그 행 ID `model_row_id`로 정확한 공급자 모델을 고른다. 다른 공급자의 같은 이름 모델을 구분하며, 재시도는 원래 실행의 행을 그대로 쓴다. 에이전트 고정 모델은 카탈로그 외래 키가 없어 모델 삭제로 다른 모델로 바뀌지 않는다.
- **English — Model row identity (039):** Native chat, context, Decisions, image, audio and realtime requests and agents select an exact provider model with the catalog row ID `model_row_id`. Same-named models of different providers stay distinct, and retries reuse the source run's row. Agent pins have no catalog foreign key, so deleting a model never silently redirects an agent.
- **한국어 — Agent Vault(040):** Vault를 Lumen MariaDB에 암호화 노트와 불변 수정 이력으로 저장하고 `/v1/vault/*`로 제공한다. 기존 채팅 메모리는 Vault로 통합되며(`memory.md`는 Vault에서 렌더링) worker가 기존 메모리를 멱등하게 가져온다. Vault는 대시보드 전용이다. Afterglow BFF가 `LUMEN_AFTERGLOW_INGRESS_SECRET`으로 서명한 `X-Lumen-Ingress` 헤더(HMAC, 120초)와 사람 Keystone 세션이 모두 필요하며, API 키·직접 Keystone 호출·임시 대화·하위 에이전트에는 Vault 도구가 없다. 비밀값이 없거나 짧으면 Vault만 꺼지고 일반 채팅은 동작한다.
- **English — Agent Vault (040):** Lumen stores the vault in MariaDB as encrypted notes with immutable revisions and serves it at `/v1/vault/*`. Existing chat memory is unified into the vault (`memory.md` is rendered from it); the worker imports legacy memories idempotently. The vault is dashboard-only: it needs both a human Keystone session and an `X-Lumen-Ingress` header (HMAC, 120 seconds) signed by the Afterglow BFF with `LUMEN_AFTERGLOW_INGRESS_SECRET`. API keys, direct Keystone callers, temporary chats and delegated children get no vault tools. A missing or short secret disables only the vault; ordinary chat keeps working.
- **한국어 — 이미지 토큰 단가:** 관리자 `media_pricing.override_mode="leaf"`는 카탈로그 media 단가 위에 바꾼 leaf만 덮고(`image_variants`는 정확한 key별), 생략·`replace`는 기존처럼 전체를 대체한다. PATCH `null` leaf는 해당 override만 지운다. 관리자 image 모델 응답에 `image_pricing_readiness`를 추가하고, 준비되지 않은 image 모델의 활성화는 409 `image_pricing_not_ready`로 거절한다(자동 비활성화 없음).
- **English — Image token pricing:** Administrator `media_pricing.override_mode="leaf"` overlays only the changed leaves on catalog media prices (exact keys for `image_variants`); omitted or `replace` keeps full replacement. A PATCH `null` leaf clears that override only. Admin image rows report `image_pricing_readiness`, and activating an unready image model returns 409 `image_pricing_not_ready` (no automatic deactivation).
- **한국어 — Gemini Models API:** Lumen API 키로 Google Gen AI SDK의 `/v1beta/models` 목록·조회, `generateContent`, SSE `streamGenerateContent`를 사용할 수 있다. Gemini 공급자는 native 생성 경로를 사용하고 OpenAI·Anthropic·Perplexity는 지원되는 텍스트·이미지 입력과 함수 호출을 Lumen 완료 코어로 변환한다. 목록·조회에는 `models:read`, 생성에는 `compat:completions:write`가 필요하며 오류는 Google 형식을 사용한다. 같은 공개 ID가 여러 공급자에 있으면 목록은 `models/lumen/<provider_id>/<model_id>`를 반환한다. 공개 ID와 `X-Lumen-Provider`를 함께 보낼 수도 있으며 모호한 공개 ID는 409로 거부한다. 서버 도구, 캐시·파일 참조, 음성·동영상·PDF, 텍스트 외 출력, 가상 `lumen` 모델, 대화 기록과 메모리는 지원하지 않는다. `countTokens`는 보수적으로 501을 반환한다. 공식 SDK 로컬 테스트(합성 upstream)는 통과했고(`docs/testing.md`) live 공급자 호출과 배포는 검증하지 않았다.
- **English — Gemini Models API:** Lumen API keys can use the Google Gen AI SDK for `/v1beta/models` list/get, `generateContent`, and SSE `streamGenerateContent`. Gemini providers use native generation; OpenAI, Anthropic, and Perplexity translate supported text, image input and function calling through Lumen's completion core. List/get require `models:read`; generation requires `compat:completions:write`; errors use the Google envelope. Duplicate public IDs are listed as exact `models/lumen/<provider_id>/<model_id>` names. Callers may instead send the public ID with `X-Lumen-Provider`; an ambiguous public ID returns 409. Server tools, cached/file references, audio/video/PDF, non-text output, the virtual `lumen` model, conversation history, and memory are unsupported. `countTokens` conservatively returns 501. Local official-SDK tests against synthetic upstreams pass (see `docs/testing.md`); no live provider call or deployment is verified.
- **한국어 — 모델 목록:** Gemini 목록은 코딩 CLI 기준이 아니라 chat 실행 가능 여부(활성·가격·chat 자격 증명·텍스트 입출력)로 모델을 고르고, 스트리밍을 지원하는 모델에만 `streamGenerateContent`를 표시한다. 같은 이름의 Gemini 임베딩 모델도 정확한 `models/lumen/<provider_id>/<model_id>`로 표시하며, 임베딩 route도 이 이름과 `X-Lumen-Provider`를 받는다. `anthropic-version` 헤더가 있는 `GET /v1/models`는 Messages로 실행할 수 있는 모델만 나열한다. / **English — Model listing:** Gemini discovery selects models by chat eligibility (active, priced, chat credential, text I/O) instead of the coding-CLI gate. It advertises `streamGenerateContent` only for streaming-capable models. Duplicate Gemini embedding names are also listed as exact `models/lumen/<provider_id>/<model_id>` routes, and the embedding routes accept those names and `X-Lumen-Provider`. `GET /v1/models` with `anthropic-version` lists only Messages-eligible models.
- **한국어 — 서버 도구 모델:** Perplexity Sonar처럼 내장 검색이 필요한 모델은 개인·서비스 키로 호출하면 예약·공급자 호출 전에 403 `model_requires_server_tools`로 거절하고, 키용 모델 목록 전체에서 숨긴다. Gemini 목록은 텍스트·임베딩을 한 이름 공간으로 보고 겹치는 공개 ID를 모두 정확한 route ID로 표시한다. 모델 키 route 허용 목록에 Gemini 목록·조회·생성·스트림·countTokens(`{model:path}`)를 추가하고 임베딩은 `embeddings:write`를 쓴다. / **English — Server-tool models:** Personal and service keys calling a model with built-in search (Perplexity Sonar) get 403 `model_requires_server_tools` before any hold or provider call, and every key-facing catalog hides such models. Gemini discovery treats text and embedding rows as one name space and issues exact route IDs for every colliding public ID. The model-key route allowlist adds Gemini list/get/generate/stream/countTokens (`{model:path}`); embeddings use `embeddings:write`.
- **문서 / Docs:** API 참조에 Python·Node.js Gen AI 예제와 OpenAI·Anthropic Python 예제를 추가한다. OpenAI는 `<origin>/v1`, Anthropic은 SDK가 `/v1/messages`를 붙이므로 origin을 사용한다. / API reference adds Python and Node.js Gen AI examples plus OpenAI and Anthropic Python recipes. OpenAI uses `<origin>/v1`; Anthropic uses the origin because its SDK appends `/v1/messages`.
- **사용 중단·제거 / Deprecated or removed:** 기존 프로젝트 귀속 API 키는 038에서 모두 개인 키로 전환된다(해시·scope·한도·수명·이력 프로젝트 보존, 프로젝트 헤더 무시, 사용자 지갑 결제). 개인·서비스 키의 `model=lumen`은 403 `model_not_allowed_for_key`로 거절하며 Claude Gateway 키만 계속 쓸 수 있다. 모든 API 키에서 hosted 도구는 403 `server_tool_not_allowed_for_key`로 거절한다. / Existing project-bound API keys all become personal keys in 038 (hash, scopes, limits, lifecycle and historical project preserved; project headers ignored; user-wallet billing). `model=lumen` returns 403 `model_not_allowed_for_key` for personal and service keys; only Claude Gateway keys keep it. Hosted tools return 403 `server_tool_not_allowed_for_key` for every API key.
- **DB:** 새 migration 5개는 추가형이다(새 테이블·nullable 열, 일부 actor 열의 NULL 허용; 기존 데이터를 지우거나 다시 쓰지 않음): `036-user-domain-scope`, `037-domain-credit-pools`, `038-model-api-key-ownership`, `039-agent-model-identity`, `040-agent-vault`. 기존 API/worker를 drain·정지하고 암호화 백업 뒤 `lumen-migrate --apply`로 모두 적용한 다음 호환 writer만 시작한다. 040 이후 이전 writer와 섞지 않는다. / Five additive migrations (new tables and nullable columns, NULL allowed on some actor columns; no existing data deleted or rewritten): `036-user-domain-scope`, `037-domain-credit-pools`, `038-model-api-key-ownership`, `039-agent-model-identity`, `040-agent-vault`. Drain and stop the old API/workers, take an encrypted backup, apply them with `lumen-migrate --apply`, then start only compatible writers. Never mix pre-040 writers with this release.
- **운영 / Operator notes:** (1) Kolla passwords에 32바이트 이상 `lumen_afterglow_ingress_secret`을 만들고 Afterglow 서명자와 같은 값을 쓴다(없으면 Vault만 꺼짐).
