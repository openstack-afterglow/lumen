## Why

The user reports a Sonar response without search sources, a tool-schema error rendered as completed, and context capacity still unavailable. Verification must cover actual transport and API/worker behavior, not only synthetic chunks. The context surface must explain what is included and how much of the total it consumes.

## What Changes

- Diagnose/fix Perplexity tool schema, native search wire parameters and truthful durable execution evidence.
- Project actual context composition, measurement provenance, unknown/deferred material and safe source names through existing context APIs and events.
- Preserve exact model-window discovery and legacy persisted context-event readability.
- Support Afterglow-owned root Compose runtime verification of current source without introducing cross-repository Python imports.

## Capabilities

### New Capabilities
- Structured context breakdown for owner-scoped prepared and runtime requests.

### Modified Capabilities
- Native search/tool failure projection and model-context resolution.

## Impact

Lumen retains provider/tool execution, durable journal, secrets and context accounting ownership. Afterglow consumes the new optional breakdown and orchestrates local deployment. No fabricated capacity, execution evidence, or token precision. No production changes, commits or pushes.
